# Setup instructions

1. Clone this repo to your system.
2. Create a file called .env.local in the project folder on your system and write your Eleven Labs API Key in the file in below format:
   ELEVENLABS_API_KEY="YOUR_ELEVENLABS_API_KEY"
3. Run the project using the commands:
   - **Install dependencies**
   - npm install
   - **Run the project**
   - npm run dev
  
4. Your website will run on some localhost url, where your website will look like this: https://nexus-hub-rosy.vercel.app/dashboard
